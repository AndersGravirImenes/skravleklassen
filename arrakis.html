01 // MONIAC

Hydraulisk spice-sirkulasjon

MONIAC MK.II — Phillips (1949) i Dune-landskap

Bill Phillips’ maskin (1949) møter Arrakis: total spice-høst (Y), skattesats (t), MPC (c), sparing til sietch (s) og importlekkasje (m); c og s deler det som ikke går til t og m (c + s = 1 − t − m) og beveger seg motsatt; offentlig forbruk fra statskassen (G), investering fra banktank (I), autonom eksport (X) via harvester (P). Sub-tanker: statskasse (skatt t), sietch-bank (s), utland (m). Likevekt når lekkasjer = injeksjoner: S + T + M = I + G + X (eller Y = C + I + G + (X − M)). Harvestere patruljerer ørkenen (levende enheter inspirert av dune-js; harvestere bruker Dune II-sprites (8 retninger) etter Dune Dynasty-enhetsdata). Phillips-maskinen ↗

02 // HANK

Heterogen spice-økonomi

HANK MK.I — Fremen vs CHOAM på Arrakis

HANK (Heterogen Arrakis New Keynesian): to agenttyper deler spice-produksjonen. Fremen (andel λ) er hand-to-mouth og bruker hele lønnsinntekten; CHOAM / stormannsgårder (1−λ) sparer i obligasjoner og har lavere MPC. Aggregert forbruk C = λ·cHM + (1−λ)·cR gir andre multiplikatorer enn MONIAC. New Keynesian kjerne: IS-kurve, Phillips-kurve (nominal rigiditet / θ) og Taylor-regel for Spacing Guild-renten (i). Keiserlig etterspørsel (G), sandworm-sjokk (ν) og inflasjonsmål (π*) driver output gap y og spice-prispress π.
